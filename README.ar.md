# Des Chiffres et des Lettres (الأرقام والحروف)

نسخة حديثة تعمل داخل المتصفح من اللعبة التلفزيونية الفرنسية الشهيرة **«Des Chiffres et des Lettres»**: ابحث عن أطول كلمة، وحقّق الرقم المطلوب، وتغلّب على الحاسوب.

> النسخة الفرنسية (الأساسية): [README.md](README.md)

## المميزات

- **أطول كلمة**: 10 حروف (تختارها أنت بين حرف علة وحرف ساكن أو عشوائياً) مع مؤقت، والتحقق من الكلمة بقاموس يضم أكثر من 180 ألف كلمة فرنسية.
- **الحساب صحيح (Le compte est bon)**: 6 أرقام ورقم مطلوب بين 101 و999 والعمليات الأربع، مع إمكانية التراجع وسجل للعمليات.
- **خصم آلي**: الحاسوب يبحث عن أطول الكلمات وأفضل حل رياضي (بحث شامل).
- **مباراة كاملة** من 6 جولات ضد الحاسوب.
- وضع فاتح / داكن / تلقائي، مؤثرات صوتية، حفظ أفضل النتائج.
- يعمل بلوحة المفاتيح وعلى الهاتف، ويمكن تثبيته وتشغيله دون اتصال (PWA).
- **بدون أي مكتبات خارجية أو خطوات بناء**: HTML وCSS وJavaScript فقط.

## التشغيل

بسبب استخدام وحدات ES وتحميل ملف القاموس، يجب تشغيل خادم محلي صغير (فتح `index.html` مباشرة لا يعمل):

```bash
git clone https://github.com/<حسابك>/chiffres-et-lettres.git
cd chiffres-et-lettres
npm start        # ثم افتح http://localhost:8080
```

يلزم Node.js بالإصدار 18 أو أحدث. ويمكن استعمال أي خادم ملفات ثابتة آخر (`python3 -m http.server` مثلاً).

## القواعد

**أطول كلمة**: اختر 10 حروف (على الأقل حرفا علة وحرفان ساكنان) ثم كوّن أطول كلمة ممكنة قبل انتهاء الوقت (30 ثانية). نقطة لكل حرف، وكلمات 9 و10 حروف تُحسب ضعفين. الكلمة يجب أن تكون في القاموس (تُتجاهل علامات التشكيل الفرنسية).

**الحساب صحيح**: اختر عدد الأرقام الكبيرة (25، 50، 75، 100) وسيُكمَّل الباقي بأرقام صغيرة (1 إلى 10). صِل إلى الرقم المطلوب بالعمليات `+ − × ÷`؛ كل رقم يُستعمل مرة واحدة، ونتائج العمليات يجب أن تكون أعداداً صحيحة موجبة. الحصيلة: 10 نقاط للنتيجة الدقيقة، 7 إذا كان الفارق ≤ 5، و5 إذا كان ≤ 10.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه المشروع (الفرع `main`).
2. من **Settings ← Pages** اختر **Source: GitHub Actions**.
3. عند كل `push` على `main` يعمل ملف `pages.yml` تلقائياً وتصبح اللعبة متاحة على `https://<حسابك>.github.io/<اسم-المستودع>/`.
